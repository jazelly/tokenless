Accept modern OpenAI function tools on Chat Completions requests, including terminal SSE tool-call frames, complete multiple-call history, every `tool_choice` mode, `parallel_tool_calls`, and `strict: true` arguments. Tokenless validates request-scoped catalogs, unique calls, contiguous one-to-one results, named choices, and recursively closed strict object schemas; it returns model-ordered schema-valid standard calls with Tokenless-owned ids or permitted final text. Streaming calls carry stable indexes, ids, names, complete arguments, optional accompanying content, `finish_reason: tool_calls`, and `[DONE]` without fabricated usage. Framing, choice, call-count, and argument violations fail with `provider_output_protocol_error` and never receive correction. A nonce-correlated allowed `kind: final` JSON string-escaping failure may receive one bounded same-provider correction before exposure; other malformed requests or provider output fail immediately with machine-readable errors, and caller tools are never executed by the API proxy.
