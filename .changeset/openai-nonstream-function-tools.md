Accept modern OpenAI function tools on Chat Completions requests, including terminal SSE tool-call frames, single-call `tool_choice` modes, `strict: true` arguments, and `parallel_tool_calls: false`. Tokenless now validates request-scoped tool catalogs, paired tool history, named choices, and recursively closed strict object schemas; it compiles the selected choice into the provider envelope and returns either one matching schema-valid standard tool call with a Tokenless-owned id or permitted final text. Streaming tool calls carry a stable index, id, name, complete arguments, `finish_reason: tool_calls`, and `[DONE]` without fabricated usage. Choice and argument violations fail with `provider_output_protocol_error` and never receive correction. A nonce-correlated allowed `kind: final` JSON string-escaping failure may receive one bounded same-provider correction before exposure; other malformed requests or provider output fail immediately with machine-readable errors, and caller tools are never executed by the API proxy.
