# Tokenless Project Instructions

## Roadmap Planning (`docs/roadmaps/`)

- `docs/roadmaps/` is Tokenless's own self-built planning system. It is not shared or public.
- All roadmap document prose must be written in Chinese (Simplified). Code, identifiers, paths, and commands inside a roadmap stay in English.
- The entire directory (including `backlog/` and `archived/`) is Git-ignored (`/docs/roadmaps/` in `.gitignore`). Never commit roadmap files or remove that ignore rule.
- Full lifecycle rules (active/backlog/archived placement, required frontmatter, disposition notes) live in [docs/roadmaps/README.md](docs/roadmaps/README.md).
